# v{version} 发布说明

> 本版本为 **ShiJian（时见）{version} 正式版**。
> 本次更新聚焦于 **全栈交互反馈与动效体系深度重设计（PLAN-INTERACTION-MOTION）** 以及 **N14 前端架构重构与实体口径对齐收口**，带来极速流畅、自然细腻的桌面交互体验。

---

## 重大更新亮点

### 1. 全栈交互反馈与动效体系深度重设计
- **双模平滑滚动与自适应滚动条**：
  - 区分普通鼠标滚轮与高精度触控板输入，引入指数阻尼物理步进算法，彻底解决滚动生硬与卡顿感。
  - 支持 `PageUp`/`PageDown`/`Home`/`End` 键盘平滑滚动与锚点导航平滑跳转。
  - 滚动条采用自适应微交互，常态保持极简纤细（`scale(0.6)`，低不透明度），在鼠标悬停或拖拽时自然平滑展开。
- **Windows 11 原生 DWM 窗口与代际锁异步浮层**：
  - 客户端窗口接入原生 Windows DWM 装饰规范（`WindowDecorations.Full` 与 DWM 物理圆角），完全保留 Windows 11 原生平滑最大化/还原动画与贴靠布局（Snap Layouts）。
  - 新增代际保护异步浮层控制器（`OverlayTransitionController`），接管全局搜索面板、模态弹窗与内置对话框，彻底杜绝快速连击与异步时序导致的弹窗遮罩重叠或失效。
- **方向感知页面切换与触感微交互**：
  - 页面容器（`PageContainer`）与设置页大类切换引入前向/后向智能方向感知滑入滑出过渡（`Forward` / `Back`），快速切换自动平滑取消并复位。
  - 侧边栏主导航增加平滑滑动指示药丸（`ActiveIndicator`）；Expander 折叠展开箭头收敛为流畅的纯 CSS 旋转过渡。
  - 下拉框与右键上下文菜单引入方位感知入场动画（`PopupMotion`），弹出自然柔和。
  - 导航条目、卡片与所有交互按钮全量接入 `150ms` 悬停 + `90ms` 点击轻触压感反馈矩阵，全部过渡参数严格收敛至 `MotionTokens` 标准令牌。

### 2. N14 前端重构与实体对齐全面收口
- **实体数据源全面对齐**：分类页、网站详情页与数据汇总页全量接入统一实体数据源与跨平台路径分段，保证各类数据口径精准互斥与统计一致。
- **视觉主题与规范微调**：全站 Nord 规范调色板与暗色/亮色模式细节收口，视觉层级更加素雅清晰。
