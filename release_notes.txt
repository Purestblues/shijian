# v{version} 发布说明

> 本版本为 **ShiJian（时见）{version} 维护更新版**，在 v2.3 基础上全面换装 **Nord 24h 环形时钟** 全新应用图标体系。

---

## 本次更新内容

### 1. 全新 Nord 24h 环形时钟应用图标
- **统一视觉语言**：告别早期继承自 Tai 的幽灵图标，采用契合时见 2.0 Nord Snow Storm / Frost 设计语言的 **24 小时分段环形表盘 + 极简指针** 图标。
- **全平台多尺寸适配**：覆盖 Windows 主程序（`16–256px` 多分辨率 ICO）、窗口标题栏、系统托盘（针对 `16×16` 小尺寸进行像素对齐加粗优化）、macOS `AppIcon.icns`（Retina 全套分片）、安装器（`.ico` / `.png`）及浏览器扩展（`48px` / `128px`）。

### 2. 包含 v2.3 全部能力
- **本地 MCP 服务端双模式（Streamable HTTP + STDIO）**：内置 `/mcp` 端点与 `--mcp` 桥接入口，支持 Bearer Token 安全鉴权、原始流水只读红线与敏感凭据脱敏。
- **独立「AI 与 MCP」设置分页**：支持一键复制 Agent 安装提示词、主流客户端配置模板与 STDIO 桥接命令。

## 下载与安装

产物由 GitHub Actions 自动构建打包，见本页下方 Assets：

| 产物 | 文件名 | 适用场景 |
| --- | --- | --- |
| Windows 安装器 | `ShiJian-{version}-Setup.exe` | 推荐普通用户使用（支持一键安装与升级） |
| Windows 绿色版 | `ShiJian-{version}-win-x64.zip` | 便携免安装使用，解压后可直接运行 |
| macOS | `ShiJian-{version}-macos-arm64.dmg` | Apple Silicon 设备，macOS 12.0+ |

> **升级提示**：本版本完全向下兼容原有本地数据与配置，安装时将自动保留原有记录数据库与图标缓存。
