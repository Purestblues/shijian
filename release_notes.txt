# v{version} 正式版发布说明

> 本版本为 **ShiJian（时见）2.0 正式版**。
> 自本版本起，正式废止历史 `v1.3.4-fork.X` 补丁序列命名规则，全面启用 **2.0 正式版体系**（后续版本将按 `2.1`、`2.2` 等主次版本规则演进）。
> 本版本汇集了 **N14 全站 UI 设计语言与前端架构彻底重构**、**N8–N13 分类与体验升级**、**N15 永久数据记录与 WebDAV 快照云同步** 以及 **G14–G22 全功能实测缺陷收口批**，代表着 ShiJian 走向独立成熟桌面级应用的里程碑。

## 重大更新亮点

### 1. 全站 UI 设计语言与前端架构彻底重构（N14）
- **Nord 极简素雅视觉基座**：全面采用对齐桌面端 Material 典范与 Nord 规范的设计语言，提供全新 `Nord Snow Storm`（雪原浅色）、`Nord Polar Night`（极夜深色）与 `Nord Frost`（北极蔚蓝）三套素雅主题。
- **一体化扁平侧边栏**：废弃悬浮毛玻璃胶囊导航舱，改为平铺一体化侧边栏与柔和胶囊指示态，兼具极高空间利用率与视觉纯净度。
- **扁平线框与清晰层级**：以画布明度差与 1px 微描边替代传统沉重阴影；彻底移除消耗 GPU 的无谓高斯模糊滤镜，全站过渡动画收敛为标准 Material 贝塞尔曲线，手感轻快丝滑。
- **全新低饱和调色板**：主色升级为典雅的矢车菊蓝（`#527CE6`），精选 12 款低饱和自然活力色板，图表配色自适应 WCAG 对比度。
- **桌面与 WebUI 令牌统一**：桌面端与内嵌 WebUI（插件管理面板）全面统一 CSS/XAML 变量令牌，视觉浑然一体。

### 2. 典型网站/应用智能自动归类与分类体系重构（N8–N11）
- **分类标签体系统一**：应用与网站全面共享同一套分类标签体系，不再割裂管理。
- **内置预设标签与 SVG 图标库**：开箱内置 9 个常用分类与 32 枚 24×24 精美 SVG 矢量分类图标，彻底告别 Emoji 图标兼容性与裂图困扰。
- **常见对象自动归类**：内置常见网站与软件的匹配规则，自动归类未分类对象，并支持在设置中一键重新智能归类。

### 3. 数据永久记录、一致性快照备份与 WebDAV 云同步（N15）
- **默认永久记录**：彻底移除原有的「1 年记录上限」，应用使用与网站浏览历史默认永久保存。
- **`.shijian-backup` 归档备份**：基于 SQLite `VACUUM INTO` 事务级一致性快照 + 图标打包 + SHA-256 校验，支持合并（Merge）与覆盖（Replace）恢复，并在导入前自动创建本地安全回滚点。
- **WebDAV 多端云同步**：支持坚果云、Nextcloud 等标准 WebDAV 服务器，支持连接测试、手动同步、定时自动同步与跨设备历史版本增量合并。

### 4. 设置页重构与应用内平滑滚动（N12 / N13）
- **设置页大类独立分页**：重构为「常规 / 外观 / 统计与规则 / 数据 / 关于」5 个独立分页，切页自动复位，告别旧版无序堆叠。
- **帧同步平滑滚动**：为应用内各滚动容器加入基于指数阻尼的平滑滚动算法，滚动手感柔和细腻，并严格遵循系统「减少动画」偏好。

### 5. 质量与全功能缺陷深度收口（G14–G22）
- **P0**：修复概览页「今日」视图偶发 `ArgumentOutOfRangeException` 导致的指标卡与图表空白。
- **P1**：修复统计页堆叠柱图多行图例裁切、柱图参考线文本碰撞重叠、详细页热力图年视图行高过密挤压、关联弹窗搜索失效及侧边栏选中高亮不同步等问题。
- **P2**：收口自定义日期面板弹出、统一实体图标回退与 favicon 预校验、修复合并组校验提示与 WebDAV 中文开关状态等细节瑕疵。

## 升级注意事项

1. **双端协同升级**：本版包含服务端数据库表结构、备份接口、WebDAV 协议与全新前端，**请同时升级客户端与服务端**。
2. **数据无损迁移**：安装包与旧版平滑兼容，会自动保留并迁移原有的 SQLite 数据库与图标资源。
3. **浏览器扩展**：扩展沿用 `2.0.2` 版本，已安装用户无需重新配置。
